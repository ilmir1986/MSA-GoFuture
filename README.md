## Ключевые архитектурные решения

| Решение                         | Обоснование                                                                 | ADR         |
|---------------------------------|-----------------------------------------------------------------------------|-------------|
| **Strangler Fig + API Gateway** | Нулевой downtime при миграции, постепенный перенос трафика                  | `Task1/004` |
| **Kafka + Flink + Camunda**     | Масштабируемая событийная шина, real-time обработка, управляемые транзакции | `Task2/006` |
| **Hybrid data isolation**       | Баланс стоимости и безопасности: DB/Schema/Row-per-tenant по тиру партнёра  | `Task5/009` |
| **Service Mesh (mTLS)**         | Zero-Trust безопасность без изменения кода сервисов                         | `Task3/007` |
| **Feature Store + ClickHouse**  | Низкая задержка для ML-инференса + быстрые BI-запросы                       | `Task4/008` |
